# GCC Compass

A React and TypeScript application for exploring India's GCC landscape, comparing cities, evaluating setup options, researching with the AI Analyst, and discovering ecosystem partners and opportunities.

## Requirements

Use Node.js 22.12 or newer and npm. Commit the package lockfile and use npm ci for reproducible installs.

## Local development

~~~sh
npm ci
npm run dev
~~~

Open http://127.0.0.1:5173. The Vite development server also mounts the AI API.

## Production

~~~sh
npm ci
npm run build
npm start
~~~

The production server serves dist/ and the AI API at http://127.0.0.1:4173 by default. Set HOST and PORT in the deployment environment when needed. For a local environment file, copy .env.example to .env and run:

~~~sh
node --env-file=.env server/index.mjs
~~~

Optional AI and research providers are configured through the application's AI Analyst settings.

## Repository contents

- src/: application components, styles, and data loaders.
- public/: required static assets, including partner logos.
- server/: the production server and AI/research services.
- dataset/processed/: CSV data required by the frontend and server; include this folder in deployments.
- scripts/: data preparation and verification utilities. Older Python browser audits are grouped under scripts/ui-audits/.

The data-preparation scripts use local research inputs that are excluded from Git; the processed runtime CSVs are included.

Internal Docs, pitch decks, research source files, generated artifacts, credentials, and build output are excluded from Git. Production serves files from dist/; build output is generated by npm run build.

## Verification

~~~sh
node --test server/*.test.mjs
node scripts/verify_opportunity_data.mjs
~~~

With the development server running, browser checks are available in scripts/verify_ecosystem.mjs, scripts/verify_opportunities.mjs, scripts/verify_ecosystem_dropdowns.mjs, and scripts/verify_header_navigation.mjs. These browser scripts currently use a local Chrome installation at the Windows path declared in each script. Screenshots are regenerated under the ignored artifacts/ directory.
